 C++ Stack and Queue Implementation

This repository contains my C++ implementation of a Stack and queue data structure using a fixed-size array.

## Features

- Push operation
- Pop operation
- Stack Overflow checking
- Stack Underflow checking
- Display stack elements
- String reversal using Stack
- Implementation a stack using Queue
- string bracket checking

 ## Technologies Used

- C++
- Code::Blocks

 ## How to Run

1. Download or clone the repository.
2. Open the `.cpp` file in Code::Blocks or any C++ IDE.
3. Compile and run the program.
